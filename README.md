# ระบบขอเวรและจัดตารางเวร

เว็บแอปสำหรับบันทึกคำขอเวร/วันหยุด และจัดตารางเวรประจำเดือนสำหรับหน่วยงานเวชศาสตร์ฉุกเฉิน พยาบาล ผู้ช่วยพยาบาล และหน่วยงานย่อยที่เกี่ยวข้อง

## ไฟล์หลัก

- `index.html`  
  ไฟล์เว็บแอปหลัก รวมหน้าขอเวร ปฏิทิน Admin, Duty Roster, การจัดเวร, Export และการเชื่อมต่อ Google Apps Script

- `google-apps-script-log.gs`  
  โค้ดฝั่ง Google Apps Script สำหรับอ่าน/เขียน Google Sheet และตรวจ Admin

- `README.md`  
  ไฟล์สรุประบบและกฎการจัดเวรล่าสุด

ไฟล์ที่แก้ไขหลักในรอบนี้คือ `index.html`


## Duty Roster

หน้า `Duty Roster` ใช้สำหรับจัดตารางเวรจากคำขอที่บันทึกไว้ โดยเลือก:

1. หน่วยงาน
2. ตำแหน่ง
3. เดือนที่ต้องการจัดเวร
4. กด `จัดเวร`

มีปุ่ม:

- `จัดเวร`
- `รีเซ็ท`
- `Export Excel`
- `ตั้งค่า` เพื่อเปิด/ซ่อนแผงตั้งค่าอัตรากำลัง

## การตั้งค่าอัตรากำลัง

แผง `ตั้งค่าอัตรากำลัง` ถูกซ่อนไว้ก่อน ต้องกดปุ่ม `ตั้งค่า` จึงจะแสดง

ตั้งค่าได้ตาม:

- หน่วยงาน
- ตำแหน่ง
- เวรแต่ละประเภทเป็นการ์ด
- จำนวนคนขึ้นเวร
- Level บังคับได้มากกว่า 1 level

ค่าที่ตั้งไว้จะจำแยกตามหน่วยงานและตำแหน่ง

## ลำดับการจัดเวร

ระบบเรียงลำดับการจัดเวรดังนี้:

```text
ด -> 6S -> ช -> ชS -> ชG -> บ
```

ลำดับตัวย่อในช่องเวรจะถูกจัดเรียงมาตรฐาน:

```text
ด / 6S / ช / ชS / ชG / บ
```

ตัวอย่าง:

- `ช/บ`
- `ชS/บ`
- `ชG/บ`

ระบบจะไม่แสดงเป็น `บ/ช`

## สัญลักษณ์เวร

```text
ด  = 00.00 - 08.00 น. เวรดึก
ช  = 08.00 - 16.00 น. เวรเช้า ER
บ  = 16.00 - 00.00 น. เวรบ่าย
ชG = 08.00 - 16.00 น. เวรเช้าหน่วยหัตถการ
ชS = 08.00 - 16.00 น. เวรเช้าคัดกรองกลาง
6S = 06.00 - 14.00 น. เวรคัดกรองกลาง
X  = วันหยุด
V  = ลาพักผ่อน
อ  = อบรม
ก  = ลากิจ
ค  = ลาคลอด
ป  = ลาป่วย
บวช = ลาบวช
```

## สีในตารางเวร

- สีแดง = เวรหรือวันที่ขอไว้
- สีเขียวอ่อน = วันหยุด `X`
- สีฟ้าอ่อน = ลาพักผ่อน `V`
- สีม่วง/น้ำเงินอ่อน = เวรที่ระบบจัดให้

## คำขอ Pending

ระบบนำคำขอ `Pending` มาจัดร่วมด้วย

- ถ้าเป็น Pending จะถูกแสดงในตารางเหมือนคำขอ
- ระบบจะแสดงหมายเหตุว่าเป็น Pending ที่นำมาจัดร่วม
- ถ้าทำให้อัตรากำลังไม่พอ ระบบจะแสดงหมายเหตุเตือนรายวัน/รายเวร เช่น จัดได้ `x/y` คน

## กฎต่อเวรสำคัญ

ระบบตรวจ hard constraints ก่อนจัดและก่อนสลับเวร:

- ห้าม `บ -> ด` ในวันถัดไป
- ห้าม `บ -> 6S` ในวันถัดไป
- เวรดึกติดกันไม่เกิน 3 ดึก
- ห้าม `ด` กับเวรเช้าในวันเดียวกัน
- `ช/บ`, `ชS/บ`, `ชG/บ` ทำได้
- `ด/บ` ในวันเดียวกันทำได้เฉพาะการแก้/ย้าย/สลับด้วยมือ แต่ระบบจัดอัตโนมัติจะหลีกเลี่ยง
- `บ/ด` ไม่อนุญาต
- ชุดเช้า+บ่ายติดกันเกินเงื่อนไขเดิมจะไม่ถูกจัด

## การสลับและแก้เวร

คลิกช่องเวรในตารางเพื่อเปิด modal แก้ไข

ทำได้:

- ย้ายเวรให้คนอื่น
- แลกเวร เช่น เช้ากับบ่าย
- แลกเวรกับวันหยุด `X`
- สลับทั้งช่อง เช่น `ช/บ` กับ `ด`
- เปลี่ยนเวรในช่อง

ข้อจำกัด:

- คนรับเวรต้องไม่ผิดกฎต่อเวร
- วันหยุด `X` ที่มาจากคำขอหยุด Approved จะถูกล็อก ไม่สามารถสลับได้
- `X` ที่ระบบจัดให้เองสามารถสลับได้

## การเกลี่ยเวร

ระบบพยายามเกลี่ยเวรให้ครบวันทำการ:

- เป้าหมายต่อคน = จำนวนวันทำการของเดือน - วันที่ลาหรือหยุดจากคำขอในวันธรรมดา
- ถ้าเวรต่ำกว่าวันทำการ ระบบจะพยายามย้ายเวรจากคนที่เกินเป้าหมายมาเติม
- สามารถดึงเวรข้าม Level ได้ ถ้าไม่ผิดกฎและไม่ทำให้อัตรากำลัง/Level ขั้นต่ำเสีย
- ถ้ายังเติมไม่ได้ ระบบจะแสดงหมายเหตุ `จำนวนเวรขั้นต่ำ`

ระบบยังพยายามให้เวร `บ` และ `ด` ใกล้เคียงกันใน Level เดียวกัน:

- คน Level เดียวกันที่ได้เวร `บ` หรือ `ด` น้อยกว่าจะถูกเลือกก่อน
- ถ้าเวรบ่ายหรือดึกต่างกันเกิน 2 เวรใน Level เดียวกัน ระบบจะแจ้งเตือน

## หน่วยงานและกฎอัตรากำลัง

### อุบัติเหตุและฉุกเฉิน

รองรับ RN และ PN พร้อมกฎอัตรากำลัง ER, หัตถการ, คัดกรอง และ Level ขั้นต่ำตามที่ตั้งค่าไว้ในระบบ

คัดกรอง:

- `6S`
- `ชS`
- `ชS/บ` ทำได้

หัตถการ:

- `ชG`
- `ชG/บ` ทำได้

### หน่วยบริการทางการแพทย์ฉุกเฉิน

รองรับตำแหน่ง `พนักงานทั่วไป`

ค่าเริ่มต้น:

- เช้า `ช`: 3 คน ต้องมี Level 2 ขึ้นไป 1-2 คน
- บ่าย `บ`: 3 คน ต้องมี Level 2 ขึ้นไป 1-2 คน
- ดึก `ด`: 2 คน ต้องมี Level 2 ขึ้นไป 1 คน

### รับ-ส่งต่อ

พยาบาล:

- เช้า `ช`: 2 คน ต้องมี Level 3 ขึ้นไป 1 คน
- บ่าย `บ`: 2 คน ต้องมี Level 3 ขึ้นไป 1 คน
- ดึก `ด`: 1 คน ต้องมี Level 3 ขึ้นไป 1 คน

ผู้ช่วยพยาบาล:

- เช้า `ช`: 2 คน ต้องมี Level 2 ขึ้นไป 1 คน
- บ่าย `บ`: 2 คน ต้องมี Level 2 ขึ้นไป 1 คน
- ดึก `ด`: 1 คน ต้องมี Level 2 ขึ้นไป 1 คน

## เงื่อนไขรายบุคคล

ตั้งค่าได้ในหน้า Duty Roster:

- ประจำ ER
- ประจำหัตถการ
- ประจำคัดกรอง
- ไม่ดึก
- ไม่จัด

มีค่าเริ่มต้น `ไม่ดึก` สำหรับบางคน เช่น:

- คุณ สถิต สาทอน
- คุณ กรอุมา ไกรเพชร
- คุณ สำเริง คงศิลา

## การอัปเดต Level

ในหน้า Manage staff:

- มีปุ่ม `บันทึก`
- การเปลี่ยน Level จะมีผลตั้งแต่เดือนถัดไป
- ไม่มีปุ่มอัปเดตเดือนปัจจุบันใน UI

## Export

ปุ่ม `Export Excel` ส่งออกเป็นไฟล์ CSV แบบ UTF-8

ข้อมูลที่ส่งออก:

- ตารางรายคน
- จำนวนเวร `ทำงาน/วันทำการ`
- จำนวนหยุด
- จำนวนเวร `ด`, `ช`, `บ`
- หมายเหตุเตือน

## Google Apps Script

ระบบเชื่อมต่อ Google Apps Script ผ่าน JSONP

ปรับ timeout ล่าสุด:

```text
default timeout = 25 วินาที
light read timeout = 35 วินาที
request/read-write timeout = 60 วินาที
read retries = 2 ครั้ง
bootstrap retry = 1 ครั้ง
```

ถ้า Apps Script ช้า ระบบจะรอและ retry มากขึ้น เพื่อลดข้อความเชื่อมต่อช้าเกินไป
